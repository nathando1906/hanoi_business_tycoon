# Roadmap

## Phase 1 — structured prototype (current)
- [x] Separate simulation engine from UI.
- [x] Store six-region and three-sector configurations in machine-readable files.
- [x] Add automated tests for core game transitions.
- [x] Add data dictionary, methodology, rules, and context docs.
- [x] Include cleaned macro and retail-market research files with caveats.
- [x] Add clearly labeled synthetic regional assumptions to support playable scenarios.
- [x] Document economic parameter ranges for scenario stress tests.

## Phase 2 — strengthen the data layer
- [ ] Replace synthetic population and establishment assumptions with extracted observations when a compatible geography is confirmed.
- [ ] Add documented geographic crosswalk and vintage.
- [ ] Collect and attribute POIs/accessibility indicators where permitted.
- [ ] Keep missing values explicit and validate source licensing.

## Phase 3 — improve simulation
- [ ] Add scenario selection and reproducible random seed in UI.
- [ ] Add capacity, payroll, inventory/working capital, and debt mechanics only with clear explanations.
- [ ] Add cross-region cannibalization and sector-specific demand logic.
- [ ] Calibrate parameters only where comparable evidence exists.

## Phase 4 — product polish
- [ ] Save/load and export results.
- [ ] Add accessibility and responsive UI checks.
- [ ] Test deployment from a clean GitHub Pages branch.
