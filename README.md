# Processed data folder

- `game_regions.json`: fictional game region coefficients.
- `game_sectors.json`: fictional sector coefficients.
- `vietnam_macro_data_cleaned.csv`: cleaned national WDI indicators supplied by the project owner.
- `hanoi_retail_market_indicators.csv`: initial market-report indicators, with source/caveat columns.
- `hanoi_local_business_data_cleaned.xlsx`: analyst-facing research workbook.
- `sources.csv`: source inventory.
- `DATA_STATUS.md`: current completeness and usage caveats.

These data files do not currently contain a complete, measured set of Hanoi population/business features by game region.
